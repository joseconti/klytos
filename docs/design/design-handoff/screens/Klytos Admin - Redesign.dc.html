Turn 2 · PHP admin

The same three ideas, as what Klytos actually is — a PHP admin in a browser

Server-rendered pages, one HTTP request per action, no SPA. So the chrome is the browser's, not an OS window, and every pattern below maps to something already in the repo: admin notices from NoticeManager, status tabs as ?status= links with server counts, the bulk-action <form method="post"> from pages.php, server pagination over list(…, 50, 0), and a footer with the render time from the dev bar. The AI dock is a partial included by templates/sidebar.php, so it survives every page load; its input posts to api/ai-chat.php. ⌘K is progressive enhancement over a CSP-nonced inline script — the page works without it.
