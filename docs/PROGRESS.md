## Project card

- Stack & target platform(s): PHP 8.1+, no framework (custom microframework), Apache + mod_rewrite, pluggable storage (flat-file JSON or MySQL/MariaDB), vanilla CSS/JS, static-site build output. See `docs/03-technical-plan.md`.

- Docs language: English (D-008)
- Security profile: `references/security/web-app.md` + `references/security/mcp-server.md` (D-003)

- Design system: **existing**, token-based (`installer/admin/assets/css/klytos-tokens.css`, 118 `--klytos-*`; frontend tokens generated by `theme-manager.php`); no design source files. UI predates Keel — no design contract, current look is the baseline (D-009)
