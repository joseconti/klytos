## Project card
- Name / one-line purpose: **Klytos CMS** — self-hosted AI-first CMS: build and manage websites entirely with AI through the Model Context Protocol (MCP), generating a static site.
- Project type: **Web app (self-hosted PHP application)** / **MCP server** (spans both — stricter rule wins on conflict)
- Stack & target platform(s): PHP 8.1+, no framework (custom microframework), Apache + mod_rewrite, pluggable storage (flat-file JSON or MySQL/MariaDB), vanilla CSS/JS, static-site build output. See `docs/03-technical-plan.md`.
- License: GPL-3.0-or-later
- Docs language: English (D-008)
- Security profile: `references/security/web-app.md` + `references/security/mcp-server.md` (D-003)
- Accessibility: **WCAG 2.2 AA + European Accessibility Act**, admin panel *and* generated output (D-007) — measured baseline ~20–25% / ~15%, see `docs/04-adoption-audit.md`
- i18n: multi — base English, 20 locales (ca, da, de, el, en, es, eu, fi, fr, gl, it, ja, nb, nl, pl, pt, ru, sv, tr, zh), custom JSON key-based mechanism (`installer/core/i18n.php`), no gettext (D-006)
- Installed base: **yes — released publicly** (GitHub Releases + self-updater + standalone installer repo); production installs with stored, encrypted data. Migrations / backward compatibility are mandatory.
- Design system: **existing**, token-based (`installer/admin/assets/css/klytos-tokens.css`, 118 `--klytos-*`; frontend tokens generated by `theme-manager.php`); no design source files. UI predates Keel — no design contract, current look is the baseline (D-009)
- Keel portability: lock + embedded v3.3.0 (both trees: `.claude/skills/keel/` + `.agents/skills/keel/`) (D-002)
- Assistant config: **full** (tools: claude, codex, copilot, cursor, gemini, windsurf) — per references/assistant-config.md (D-010). Gemini via `.gemini/settings.json` `context.fileName` → `AGENTS.md`, no `GEMINI.md` mirror.
- Models: orchestrator = session model (strongest available) / reviewer = mid tier / mechanical = cheapest tier — concrete names live only in each tool's agent config (D-011)
- Keel baseline: v3.3.0
- Website intent: **yes** — klytos.io; Phase 8 deferred until requested (D-012)
- Client budget: **no** — own project (D-013)
- User guide: n/a until Phase 6
- Docs theme: n/a until Phase 6
